# 问间官网

当前版本：Mac、Windows、Android 与 iPhone/iPad Web App 统一为 **3.141（343）**。旧桌面版首次升级请先保存并正常退出，再手动覆盖安装；343 及以后保留签名更新能力。


网站地址：<https://largetomatoes.github.io/wenjian-web/>。GitHub Pages 从 `main` 分支根目录发布，使用原生 HTML、CSS、JavaScript，不需要构建或第三方前端依赖。

## 页面结构

- 首屏：可点击的问题树与交叉联系，卡片可以演示关联到问题。
- 阅读：电脑端 PDF / EPUB 对照阅读实机截图。
- 成文：随手记录、关联问题、共同思考、选入文稿的交互示意，段落来源按需展开。
- 形成过程：保留最初记录、后续理解和修改原因的示意。
- 辅助能力、本地资料、各平台下载与常见问题。

交互演示使用虚构记录，没有上传表单、个人资料、账号或数据同步。它用于介绍软件，不是在线版问间。

## 更新清单维护

官网通过 GitHub Actions 发布。每次推送、每小时及手动运行会读取公开 Releases，刷新 `updates/releases.json`，不向客户端提供令牌。发布新版本后，可手动运行 “Website and public update index” 让更新即时生效；定时刷新可能受 GitHub 排队影响。Mac 337 起首先读取此清单，备用站点沿用原安装签名校验。
