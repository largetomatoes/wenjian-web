Mac · 首次安装与打开
  1. 下载 Mac 版 ZIP，双击解压，将「问间.app」移入「应用程序」。当前安装包适用于 Apple 芯片 Mac。
  2. 双击打开问间。由于尚未取得 Apple 开发者签名与公证，首次打开可能提示无法验证开发者或无法检查恶意软件。
  3. 确认安装包来自本页链接后，打开「系统设置 → 隐私与安全性」，向下找到问间的拦截提示，点击「仍要打开」。这个按钮通常需要先尝试打开一次应用才会出现。
  4. 按系统提示确认「打开」，必要时输入这台 Mac 的密码或使用 Touch ID。之后可从「应用程序」或程序坞正常打开。

Apple 官方首次打开说明 ↗

iPhone / iPad · 添加到主屏幕

Web App 在部分网络环境下需要代理（梯子）才能访问。添加到主屏幕后，联网和同步仍受当前网络环境影响。

  1. 使用 Safari 浏览器打开上方「打开自己的问间」链接；若在微信等应用中查看此页，先复制链接到 Safari。
  2. 点击 Safari 的分享按钮（方框向上箭头）。部分版本需先点「更多」才能看到「分享」。
  3. 在分享菜单中向下滑，选择「添加到主屏幕」。若未显示，在「编辑操作」中找回该选项。
  4. 名称保留「问间」；若显示「作为网页 App 打开」，请开启，然后点击「添加」。
  5. 回到主屏幕，从问间图标进入，再连接自己的坚果云账号与第三方应用密码，或导入本地文件。以后从这个图标打开即可。

Windows · 安装与更新

下载「安装版」，运行安装程序，选择安装磁盘与文件夹后继续。更新时选择现有安装位置即可。关闭窗口可选择收起到系统托盘，再次点击托盘图标即可恢复。

升级前可在设置中导出完整备份。公开版本可从「设置 → 版本与更新」检查更新；各平台版本与安装包以本页对应的下载入口为准。Windows 安装包尚无商业代码签名。

开始之前

再回答几个问题。

这张网页会保存我的笔记吗？

这里是演示，使用虚构内容，刷新即重置。它不连接云端，也不收集你在演示中输入的内容。正式使用请下载应用，或打开独立 Web App。

一定要围绕一个很大的问题使用吗？

不必。你可以处理独立的小问题，再用汇总页重新组织它们；原问题页保留原来的结构。暂时没有归属的念头，可以先放进卡片集。

我的书和笔记如何在设备之间同步？

应用本地优先。需要跨设备时，连接自己的坚果云账号与第三方应用密码；点击同步会处理笔记、批注与书籍。各端使用同一资料库，冲突保留版本供你处理。Web App 首次使用建议添加到主屏幕后再连接。

可以免费使用、修改或介绍问间吗？

允许个人学习、研究、学术创作与公司内部使用，也允许用问间创作并发表或出售文章和书籍。对外发行须提供对应源码、构建说明与修改记录，并沿用项目许可；转售软件、付费解锁、收费托管等商业发行需另行授权。详情以仓库中的 LICENSE 与品牌政策为准。
